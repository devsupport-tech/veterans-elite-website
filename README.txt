VETERANS ELITE CONTRACTORS - WEBSITE FILES

This folder contains your new modern, SEO-optimized website.

1. PHONE NUMBER

   - Also update the tel: links (search for "tel:+18585550123")

2. EMAIL ADDRESS
   - Replace "info@veteranselitecontractors.com" with your real email

3. IMAGES
   - Replace placeholder images with real photos:
     * Team photo for hero section
     * Before/after restoration photos
     * Team photo for About section
   - Recommended image sizes:
     * Hero: 800x600px
     * About: 600x800px
     * Logo: 200x200px (replace SVG logo if you have a custom one)

   - Options to make it work:
     a) Use Formspree.io (free): Change form action to your Formspree URL

     c) Connect to your own backend/email service

5. SOCIAL MEDIA LINKS
   - Update Facebook, Instagram, Yelp, and Google links in footer and contact section

6. GOOGLE ANALYTICS
   - Add your Google Analytics tracking code to index.html (before </head>)

========================

HOW TO DEPLOY:
==============
Upload all files to your web hosting provider. Popular options:

1. Traditional Hosting (GoDaddy, Bluehost, etc.)
   - Upload via FTP or file manager
   - Point domain to the folder

2. Netlify (recommended, free)
   - Drag and drop the folder at netlify.com/drop
   - Connect your domain

3. GitHub Pages (free)
   - Create a repository
   - Push files and enable Pages
